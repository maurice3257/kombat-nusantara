Folder aset opsional.
Game TIDAK membutuhkan file apa pun di sini: karakter, stage, efek dan semua suara
dibuat secara prosedural lewat Canvas & Web Audio.

Ingin memakai suara sendiri? Taruh file .wav di assets/audio/sfx/ dengan nama:
hit_light, hit_medium, hit_heavy, hit_special, block, whoosh_light, whoosh_heavy,
projectile, rising, jump, land, ko, fight, victory, super, counter, select, confirm
lalu set CONFIG.USE_AUDIO_FILES = true di js/config.js.
